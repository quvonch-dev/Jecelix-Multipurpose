# Jevelix — Multipurpose Responsive Website

This is a static HTML/CSS/JavaScript landing page inspired by multipurpose premium theme layouts.

## Files

- `index.html` — all page sections
- `style.css` — responsive design and animations
- `script.js` — mobile menu, scroll reveal, portfolio filter, testimonial slider, FAQ accordion and demo form

## How to run

Open `index.html` in your browser, or open the folder in VS Code and use Live Server.

## How to edit

- Change text in `index.html`
- Change colors from `:root` variables at the top of `style.css`
- Change JS behavior in `script.js`

## Note

This is not the original Jevelin WordPress theme. It is a custom educational static template with a similar multipurpose structure.
